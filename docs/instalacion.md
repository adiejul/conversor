# Instalacion

### Requisitos:
- Python
- Git

### Procedimentacion:

Desde la terminal ejecuta los siguientes comandos:

1. Clona el repositorio:  

    ```bash
    git clone https://github.com/adiejul/conversor.git
    ```

2. Entra en la carpeta:

    ```bash
    cd conversor
    ```

3.  Ejecuta el programa:

    ```bash
    python conversor.py
    ```
