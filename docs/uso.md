# Uso


En primer lugar hay que ejecutar el programa:

```bash
python conversor.py
```

El uso paso a paso es el siguiente:

1. Al haber ejecutado nos va a mostrar por terminal el siguiente mensaje:

    ```text
    Conversor de temperaturas
    1. Celsius a Fahrenheit
    2. Fahrenheit a Celsius
    Elige una opcion (1 o 2): 
    ```

2. Como nos dice la terminal, escogeremos 1 o 2, dependiendo de lo que queramos hacer. Yo voy a probar la opcion 1, de Celsius a Fahrenheit.

3. A continuacion, nos va a pedir que Introduzcamos la temperatura. Yo voy a introducir 40 y doy a enter.

4. Automaticamente nos saldra por la terminal el resultado:
   
    ```text
    40.0ºC = 104.0ºF
    ```

En terminal quedaria de la siguiente manera:

```text
Conversor de temperaturas
1. Celsius a Fahrenheit
2. Fahrenheit a Celsius
Elige una opcion (1 o 2): 1
Introduce la temperatura: 40
40.0ºC = 104.0ºF
```
