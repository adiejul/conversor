# Conversor de temperaturas

Aplicacion de consola escrita en Python que convierte temperaturas entre grados Celsius y Fahrenheit.

## Requisitos

- Python
- Git

## Uso rápido

```bash
git clone https://github.com/adiejul/conversor.git
cd conversor
python conversor.py
```

El programa muestra un menu y despues de elegir la opcion que deseas e introducir los grados, muestra la conversion.

## Documentacion:

La documentacion completa esta en la carpeta 'docs' y se genera con [MkDocs](https://www.mkdocs.org/):

```bash
pip install mkdocs
mkdocs serve   # previsualizar en http://127.0.0.1:8000
```
